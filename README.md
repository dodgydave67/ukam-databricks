# UKAM on Databricks

Short production guidance for running
[`uk_address_matcher`](https://github.com/moj-analytical-services/uk_address_matcher)
on Databricks.

The documentation contains the recommended cluster setup, DuckDB settings,
canonical-data staging, and production matching notebook.

Documentation: <https://dodgydave67.github.io/ukam-databricks/>

Every push to `main` rebuilds the MkDocs site and publishes it to `gh-pages`.
